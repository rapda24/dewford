# Dewford 관리자 실행 안내

실제 사이트는 **Cloudflare Workers + D1**으로 운영합니다. 관리자 비밀번호 설정과 배포 방법은 [Cloudflare 운영 안내](cloudflare-setup.md)를 확인하세요.

아래 Python 3.9 이상·SQLite 방식은 별도의 로컬 실행 방법입니다. 추가 패키지 설치 없이 사용할 수 있습니다.

## 서버 없이 화면 미리보기

`admin.html` 파일을 브라우저에서 직접 열면 로그인 없이 예시 데이터로 관리 화면을 확인할 수 있습니다. 정적 호스팅에서 API가 없는 경우에도 미리보기를 표시합니다. `admin.html?preview=1`로 명시적으로 열 수도 있습니다.

글쓰기·수정·이동·상담 상태 변경은 미리보기 데이터에만 반영됩니다. 가능한 경우 탭의 sessionStorage에 저장되며, 실제 서버와 공개 사이트에는 반영되지 않습니다. 상단의 **예시 초기화**로 원래 예시를 복원합니다. 실제 상담 정보나 비밀번호를 입력할 필요가 없습니다.

## Python 로컬 서버 최초 실행

프로젝트 루트에서 실제 사용할 관리자 계정을 생성합니다. 기본 계정이나 공용 비밀번호는 없습니다.

```sh
python3 server/app.py --create-admin admin
```

12자 이상의 비밀번호를 두 번 입력합니다. 같은 아이디로 다시 실행하면 비밀번호를 변경합니다. 실행 중인 서버가 있다면 변경 후 재시작하여 기존 세션을 만료시키세요.

```sh
python3 server/app.py --port 8000
```

- 로그인: http://127.0.0.1:8000/admin-login.html
- 관리자: http://127.0.0.1:8000/admin.html
- 홈페이지: http://127.0.0.1:8000/

HTML 파일을 직접 열거나 일반 정적 서버로 실행하면 인증·저장·상담 접수는 작동하지 않습니다. 위 서버로 접속해야 합니다.

## 기능

- 이벤트, 유치부 캘린더, 초등부 캘린더: 글쓰기, 수정, 삭제, 게시판 이동, 위·아래 순서 변경.
- 캘린더 날짜 변경은 수정 화면에서 가능합니다. 게시판 간 이동 시 날짜와 본문을 편집할 수 있습니다.
- 로그인 상태에서는 공개 이벤트 목록·상세와 캘린더에서도 관리자 버튼이 표시됩니다.
- 상담 내역: 이름·내용 검색, 상태 필터, 전체 내용 확인, 신규 / 상담 중 / 완료 상태 변경, 삭제.
- 홈페이지·입학 상담·Contact 폼의 제출 내용이 관리자 화면에 저장됩니다. 기존 이메일 앱 호출은 이 페이지들에서 서버 접수로 대체됩니다. 자동 이메일 발송은 포함하지 않습니다.
- 이벤트 대표 이미지는 프로젝트의 `assets/` 파일 경로나 HTTPS 이미지 주소를 입력합니다. 이미지 파일 업로드 기능은 포함하지 않습니다.
- 이벤트 편집의 본문은 빈 줄로 문단을 나누며, 기존 상세 페이지의 소제목과 추가 사진도 편집할 수 있습니다.

## Python 로컬 서버 데이터와 운영

- 최초 실행 시 기존 이벤트 데이터와 캘린더 JSON을 가져옵니다. 이후 데이터는 `.dewford-data/dewford.sqlite3`에 저장됩니다.
- 데이터 폴더는 Git과 HTTP 공개 대상에서 제외됩니다. 서버를 중지한 상태에서 폴더를 백업하세요.
- `DEWFORD_DATA_DIR` 환경변수로 영구 저장 위치를 변경할 수 있습니다.
- 서버 재시작 시 게시글·상담·계정은 유지되고, 메모리의 로그인 세션은 만료됩니다. 로그인 유효 시간은 8시간입니다.
- 비밀번호는 개별 salt와 PBKDF2-SHA256 600,000회로 해시합니다. HttpOnly/SameSite 쿠키, 변경 요청의 CSRF 검사, 로그인 시도 제한, 상담 제출 제한을 적용합니다.
- 실제 외부 서비스로 배포할 때는 HTTPS 역방향 프록시 뒤에서 실행하고 `DEWFORD_ORIGIN=https://실제도메인`을 설정합니다. 정적 파일만 업로드하는 호스팅에서는 이 서버가 실행되지 않으므로 Python 프로세스와 영구 디스크를 지원하는 호스팅에 연결해야 합니다. 현재 변경에는 외부 배포가 포함되지 않습니다.
- 개인정보 동의 문구와 실제 보관·삭제 절차는 운영자가 관리하며, 상담 내역은 관리자에서 삭제할 수 있습니다.

## Python 로컬 서버 검증

```sh
python3 -m unittest discover -s server -p 'test_*.py' -v
```

테스트는 임시 데이터베이스를 사용합니다. 로그인·로그아웃, 권한 차단, CSRF·외부 Origin 차단, 게시글 작성·이동·순서·삭제, 날짜·이미지 검증, 상담 접수·조회·상태·삭제, 비공개 파일 차단을 확인합니다.
