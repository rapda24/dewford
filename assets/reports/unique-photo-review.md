# 이미지 교체 검증

- 메인과 서브페이지 15개, 총 16개 HTML에 콘텐츠 사진 145개를 서로 다르게 적용했습니다.
- 내장 image_gen으로 141개 이미지를 생성했습니다. 프롬프트와 저장 경로: [unique-photo-plan.json](unique-photo-plan.json).
- 책 방향 오류 4장(index-22, 53, 54, 56)을 수정하고 v2 이미지를 적용했습니다.
- 사진 경로 및 SHA-256 비교에서 중복 0건, 누락 파일 0건입니다. 공통 로고·아이콘·슬라이더의 실행 중 복제 요소는 제외했습니다.
- 전체 16개 페이지의 태그 구조, 영상 소스, 폼이 보존되었고 캘린더 본문은 공백입니다.
- 생성 사진을 검토하고 메인 및 Student Outcomes의 실제 브라우저 배치를 확인했습니다. 전체 페이지의 모든 화면 크기를 브라우저에서 검증한 것은 아닙니다.
- 검증 수치: [unique-photo-validation.json](unique-photo-validation.json).
